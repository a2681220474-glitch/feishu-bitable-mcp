# 真实接口验收摘要（2026-11-18）

本页仅记录开发分支的一次独立测试，不代表稳定版发布或所有租户、文件类型均已兼容。
真实资源链接、记录 ID、账号资料、回执、文件和日志保留在被 Git 忽略的私有目录，未发布。

## 方法与认证边界

维护者明确授权了三个专用 Wiki 测试资源及非删除测试。先解析到真实 docx、在线表格和 Base，再以同一用户身份读取、预览、提交和回读。
另在该用户云盘建立独立测试目录，用于创建文档、Base、在线表格和虚构 XLSX。

测试使用 FastMCP 内存客户端调用实际业务工具，通过验收专用传输桥让官方 Lark CLI 1.0.88 处理已有用户凭证、调用真实飞书接口；Python 不导出原始 Token。
用户身份和授权 Scope 来自已验证的 CLI 登录状态。公开服务仍使用自己的 OAuth 代理与逐用户令牌，测试桥没有作为产品后端发布。

**已验证：** 工具参数、白名单、预览/确认/回执、真实 API 的权限与请求/响应，以及写入后的数据。
**未验证：** 新版 ChatGPT 网页端通过公网 HTTP 完成 OAuth 登录、刷新、撤销和写操作确认的完整流程；本轮未替换原 MCP 服务、改动应用权限或重建隧道。

## 结果

共 15 种具名操作、18 次成功 MCP 变更；额外的文件夹/样本准备与权限探针不计入工具成功次数。

| 资源 | 实际操作 | 回读或核对 |
| --- | --- | --- |
| 多维表格 | 创建 Base、数据表、基础字段；单条/批量新增与更新 | 元数据正确；3 条测试记录值正确；2+1 分页不重复、不丢记录 |
| 云文档 | 创建文档；向指定测试文档追加两个段落；修改本次新增段落 | 创建标题与目标块文本正确；未覆盖已有正文 |
| 在线表格 | 创建工作簿；在指定测试表中新建独立工作表；写值/公式、基础格式及追加 | 值与公式回读正确；官方公式自检 status=success，1 条公式、0 错误 |
| 云盘 XLSX | 创建上传；同 file_token 覆盖修改指定格；另测带图表/样式的虚构工作簿 | 指定值正确；原公式、长文本 ID、合并、冻结、样式、图表和另一工作表保留；无关 ZIP 条目解压内容相同 |
| 链接解析 | 三种 Wiki 入口 | 返回实际资源类型、后续工具可使用的直接 URL；Base 返回可见数据表 URL |

审计中没有 DELETE 请求；收尾时没有待处理的 started/unknown 回执。所有测试数据均保留，未执行清理删除。
一次测试桥在网络派发前发生流读取错误，已核实无上传请求、保存证据并离线核对旧回执后，才以新请求 ID 重试；没有盲目重放不确定写入。

## 实测发现与修复

1. 细粒度 `base:record:read` 并不等于旧记录列表接口要求的 `base:record:retrieve`。旧 GET 和旧 search 都列后者，简单切换 HTTP 方法不能解决。
   依据[官方 CLI 1.0.88 的记录读取实现](https://github.com/larksuite/cli/blob/2829ecd18846d8390dfac558125f602b07232206/shortcuts/base/record_ops.go)，增加只读 Base v3 接口。
   按实际用户 grant 选择；旧应用/旧 Scope 保留原接口。不更换身份，不替用户增加授权。
2. v3 返回字段向量和数据矩阵，新增无损映射及 offset/revision 游标。保留原矩阵、字段 ID/类型和未知元数据；游标绑定用户、表、视图，版本变化要求重读。
   v3 本项目每页最多 200 条，返回 effective_page_size；不伪造上游 total。末页 observed_record_count 仅表示截至该页的累计位置。
3. 当前用户的 Sheets 编辑授权是细粒度 `sheets:spreadsheet:write_only`，同时具备读取/创建权限，不含旧列出的两个宽权限；真实新增工作表、写值、追加和样式接口仍成功。
   因而接受该明确 grant；仍要求写开关、操作/资源白名单和确认，不把读取权限当作写权限。
4. Wiki 解析增加直接资源 URL 和受读取白名单过滤的数据表 URL，减少使用者手工转换链接。写操作继续要求精确的直接目标白名单。

## 保留的限制

- 不保证严格原子 CAS；外部编辑仍有竞态窗口。
- 没有证明所有高级字段、复杂文档块或任意第三方 XLSX 都可编辑。
- XLSX 同 token 内容覆盖已在虚构样本验证；版本历史/版本号接口及冲突策略未完成真实验收，覆盖开关继续默认关闭。
- 本轮未新增授权，没有验证新的浏览器 OAuth 同意流程，也不代表其他使用者已获权限。
- 未逐项隔离验证所有最小 Scope 组合，也未进行两名真实用户的并发隔离验收；这部分仍由 Mock 覆盖并等待独立环境验收。
- 未发布新版本；历史私有原型、已发布 v0.1.x、旧 rc1 资产与本开发分支的验证记录应分别理解。
